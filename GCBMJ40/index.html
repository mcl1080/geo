Finder Unlock

This page only decrypts. It does not generate new payloads, and it does not send anything anywhere.

What it needs You need both pieces: the encrypted payload from the listing and the correct passphrase found in the field.
Real crypto The message is unlocked with AES-GCM after deriving the key from the passphrase using PBKDF2-SHA-256.
Why offline matters This works without internet access once the file is saved locally, making it useful for cache solving in the field.
